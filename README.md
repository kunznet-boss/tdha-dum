# tdha-dum
Sua IA concorda com tudo? Isso pode custar caro. Criei o TDAH-KNZ para mudar essa relação: menos ruído, mais clareza, uma decisão por vez. Uma IA que questiona, explica riscos e respeita as limitacoes do TDAH e dislexia. Acompanhe o projeto e ajude a construir uma IA que pense com você, não por você.
